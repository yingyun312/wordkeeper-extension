# 截图目录

把项目截图放在这里，然后在根目录 `README.md` 的“界面预览”部分取消注释。

建议文件名：

| 文件 | 内容 |
| --- | --- |
| `01-library.png` | 学习库首页，显示英英释义、音标、难度和话题 |
| `02-review.png` | 今日复习卡片，显示答案和评分按钮 |
| `03-reading.png` | AI 生成的阅读材料与理解题 |
| `04-export.png` | 导出资料页面 |
| `05-selection.png` | 可选：网页选中文字后的“收藏并翻译”浮动按钮 |

截图建议：

- 使用浅色界面，宽度不低于 1200px；
- 避免出现 API Key、邮箱、姓名或其他个人信息；
- 示例内容使用自己编写的英文，不要使用有版权的长段文章；
- 可以用 macOS 的 `Command + Shift + 4` 截图，或 Chrome DevTools 的设备模拟截图。
